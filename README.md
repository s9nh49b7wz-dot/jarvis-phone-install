# Jarvis for Your Phone 🤖

This repository helps you install an open-source **Jarvis-style AI assistant** on your Android phone.

## Recommended: Open Jarvis (Best overall)

**Open Jarvis** is a lightweight, open-source Android AI agent that lets you control your phone with voice & AI. No root required.

### Quick Install Steps

1. **Download the APK**  
   Go to the official releases:  
   🔗 https://github.com/tokenarc/open-jarvis/releases  
   Download the latest `.apk` file.

2. **Install on your phone**  
   - Transfer the APK to your phone (or download directly).  
   - Tap the file.  
   - Allow "Install from unknown sources" if prompted.  
   - Complete the installation.

3. **Grant permissions**  
   - Open the app.  
   - Grant **Accessibility Service** permission.  
   - Grant **Overlay** (display over other apps) permission.

4. **Set up AI**  
   - Go to Settings → AI Provider.  
   - Choose Groq (free & fast), Gemini, OpenRouter, or a local model.  
   - Paste your API key (or download a local model for offline use).

5. **Start using Jarvis**  
   - Tap the floating Jarvis pill.  
   - Speak or type commands like:  
     - "Open WhatsApp and text Mom I'm on my way"  
     - "Set an alarm for 7am"  
     - "Search for flights to New York"

## Safety Notes

- Only download APKs from the official GitHub Releases pages listed above.
- Review permissions carefully.
- Prefer projects that support local/offline models for privacy.
